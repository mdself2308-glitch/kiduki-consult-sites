# 問い合わせフォーム関連 文言確定稿(マスター)

> 送信の仕組み(SMTP・DB保存・スパム対策)は `docs/phase1-instructions.md` の T2A・T2B に従う。本書は文言のマスター。

## 通知メール(メール1)

- 宛先: **2箇所**(メイン+院長の携帯で受けられる予備アドレス)
- 送信元: `info@kdkconslt-sngyouijm.com`(固定)/**Reply-To: [your-email]**(受信箱からそのまま返信できるように)

```
件名: 【HP問い合わせ/[inquiry-type]】[your-company] [your-name]様

本文:
サイトの問い合わせフォームから受信しました。

■会社名: [your-company]
■業種: [industry]/従業員数: [company-size]
■種別: [inquiry-type]
■内容:
[your-message]
■氏名: [your-name]([your-title])
■メール: [your-email]/電話: [your-tel]
```

## 自動返信メール(メール2)

- 宛先: [your-email]
- **送信元は必ず受信監視しているアドレス(info@等)。no-reply系は使用禁止**(本文の「本メールに返信」を成立させるため)

```
件名: 【自動返信】お問い合わせありがとうございます|KIDUKIコンサルティング産業医事務所

本文:
[your-name] 様

お問い合わせを受け付けました。内容を確認のうえ、2営業日以内に担当医師よりご連絡いたします。
お急ぎの場合は、恐れ入りますが本メールにそのままご返信のうえ、件名の冒頭に【至急】とお書き添えください。

――以下、送信内容の控え――
(通知メールと同じ項目を掲載)

KIDUKIコンサルティング産業医事務所
【住所・URL】
```

## サンクスページ(/contact/thanks/)本文

```
お問い合わせありがとうございました。
内容を確認のうえ、2営業日以内に担当医師よりご連絡いたします。

お急ぎの場合は、お手元に届く自動返信メールにそのままご返信のうえ、件名の冒頭に【至急】とお書き添えください。
```
(※noindex設定を忘れない)

## フォーム下のフォールバック文言(常設)

```
フォームが送信できない場合は、お手数ですが info@kdkconslt-sngyouijm.com まで直接メールでご連絡ください。
```

## 方針メモ

- **電話番号はサイトに一切掲載しない**。連絡手段はフォーム+直通メールの二本立て
- フォームの「電話番号(任意)」欄はお客様の折り返し先(こちらから架電する用)であり、掲載方針とは別物
