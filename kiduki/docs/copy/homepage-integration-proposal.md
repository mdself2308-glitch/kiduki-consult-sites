## 0. クリニックと矛盾しないための7原則（両サイト共通）

クリニック公開文「会社や産業医から当院へ受診を手配する形はとっていません」
「特定の企業の従業員に受診を勧めるものではありません」「企業向けの相談は
KIDUKI事務所へ」と**鏡合わせ**になるように書く。

1. **受診の手配をしない・書かない。** 受診は常に本人起点
2. **特定医療機関の名称・リンク・「併設/連携」を書かない**（既存規律の維持）。
   制度の一般名（療養・就労両立支援指導、両立支援外来）は書いてよい
3. 受診勧奨に触れる箇所には必ず
   **「受診先はご本人が選びます。特定の医療機関を指定・紹介しません」**を併記
4. **会社契約の医療検査商品を作らない・載せない**（ドックはクリニックの
   個人向け自費。症状あり＝保険）。B2Bの客観評価は非医療のみ
5. **疾患が疑われたら非医療評価を中断し保険診療へ案内**する旨を明記
   （クリニック§0の振り分けと同じ文構造にする）
6. **主治医と産業医の役割分離**を両サイトで同じ言葉で書く
   （診療は医療機関、就業上の判定は職場側。クリニック側も同旨を掲載済み）
7. **本人の同意なく会社へ渡る情報はない**・会社が見るのは判定に必要な
   結論だけ（WorkTreatページの記載と同水準の言い方にする）

```
# 休職・復職判定支援
## 診断書と職場の間を、記録が残る形でつなぎます

休職していた社員から「就業可能。ただし残業は控えめに」という診断書が
届く。出社は来週。残業は何時間までなら良いのか、深夜業や運転はどう
するのか、いつまで制限を続けるのか——診断書からは読み取れません。
判断の責任だけが、人事の手元に残ります。

休職に入る場面も同じです。「療養を要す」の一行から、休ませるのか、
業務調整で支えるのか、期間をどう区切るのかを決めるのは会社です。

当事務所は、休職の始まりから復職、措置の解除までを、一続きの案件として
お引き受けします。休職開始時の判定（面談と意見書）のみのご依頼も
承ります。

## 提供内容（1案件・約3ヶ月）

- 主治医への照会状の作成。医学情報を、就業判断に必要な形で照会します
- 面談3回。復職前の判定面談、復職後2〜4週のフォロー面談、
  措置解除の判定面談
- 就業上の措置に関する意見書。措置の内容・開始日・再評価日・解除条件の
  4点を必ず記載します
- 客観生活リズム評価。2〜4週間の実測データによる生活リズムの確認
  （標準で実施・ご本人の同意制。詳細は下記）
- 記録一式の納品。面談記録・意見書・会社の決定の記録をまとめて
  お渡しします。お預かりしたままにはしません

## なぜ「期限と解除条件」を必ず書くのか

措置は、かけるより解くほうが難しいものです。期限と解除条件のない配慮は
見直されないまま続き、ご本人のキャリアと職場の運用の両方に負担を
残します。当事務所の意見書は、解除から逆算して書きます。

## 客観生活リズム評価（標準）

当事務所の復職判定は、問診の印象だけで行いません。2〜4週間の
アクチグラフ（腕時計型の活動量計）と睡眠日誌の実測データで生活リズムの
安定を確認し、勤務準備性の評価レポートとして意見書に添えます。
これは判定支援に標準で含まれます（追加料金はありません）。

- これは医療機関の検査ではありません。質問票などと同じ、就業判断の
  ための評価です。診断は行いません
- 装着はご本人の同意によります。同意されない場合も、面談による判定で
  対応します（不利益はありません）
- 実測の生データを扱うのは医師のみです。会社にお渡しするのは、
  判定に必要な結論だけです
- いびき・強い眠気など病気が疑われる所見があった場合は、評価を中断し、
  保険診療での検査・受診をご本人にお勧めします。受診先はご本人が
  選びます。当事務所が特定の医療機関を指定・紹介することはありません
- すでに医療機関で受けた睡眠の検査・健診の結果や、ご本人のウェアラブル
  記録をお持ちの場合も、勤務準備性の評価に活用できます。評価レポートには
  データの取得方法を明記します

## 主治医との連携について

主治医が、ご本人の同意のもとで勤務先の産業医等に治療と仕事の両立に
必要な情報を提供する仕組みが、保険診療に用意されています
（療養・就労両立支援指導）。当事務所が産業医等としてその情報提供を
受け取り、就業上の判断に反映します。診療は主治医、就業上の判定は
職場側——役割を分けたまま、必要な情報だけがつながります。

## 判断の主体について

就業上の措置を最終的に決定するのは、法令上、事業者です
（労働安全衛生法）。当事務所が行うのは、決定に必要な医学的な意見と、
決定の過程を後から説明できる記録づくりです。

## 措置のその後

意見書に書いた再評価日を追いかけ、期限が来た措置を見直す——この運用を
続ける仕組みが必要な場合は、月々の産業医業務としてお引き受けします。
ご相談ください。

[初回のご相談（15分）]

## 2. Casetraサイト（casetra.jp）トップ全文案

> 実装は casetra_active 側。本書が文言マスターの原案。
> 禁止語彙（使っていないことを公開前に検証する）: 一元管理／見える化／
> 従業員の健康状態を把握／健診結果・ストレスチェックの管理／
> 健康経営の推進／ウェルビーイング／ケア／カウンセリング／寄り添う

```
# その就業配慮、解除条件は書いてありますか。

Casetraは、産業保健の案件を1件ずつ確実に閉じるための業務基盤です。
健康データを溜めるシステムではありません。

## 「残業は月45時間まで」と書いた紙が、2年後も生きている

担当者が代わり、期限を追う仕組みがないまま、措置だけが残る。
誰も悪意はありません。ただ、誰も終わらせていないだけです。
産業保健の現場で最も多い滞留は、これです。

## Casetraの型

案件が開く → 判断材料が揃う → 会社が決定する → 期限が来たら見直す →
解除して閉じる。

- 措置は4点セットで記録します: 内容・開始日・再評価日・解除条件
- 決定するのは会社です。産業医の意見と会社の決定は別々に記録され、
  決定が記録されない案件は閉じられません（労働安全衛生法の建付けの
  とおり、就業上の措置の決定は事業者に残ります）
- 再評価日が来ると、案件が自動で動き出します。担当者の記憶に頼りません

## 復職案件での使われ方

主治医への照会、面談、意見書、会社の決定、復職後のフォロー、措置の
解除まで——復職1案件の全工程が、1つの案件として時系列で記録されます。
閉じた案件の記録は一式でお渡しできます。

## 主治医側からの受け取り

主治医がご本人の同意のもとで作成した勤務情報や意見書を、会社側の
受け皿として受け取れます。

- ご本人の同意なく共有される情報はありません
- 届くのは、就労上の配慮に関する要約や計画など、会社側の判断に必要な
  範囲だけです。診断名の詳細や治療の内容は含まれません

## 健康管理システムとの違い

健康管理システムは「従業員」を単位にデータを蓄積します。
Casetraは「案件」を単位に完了させます。
近いのは健康管理ではなく、是正措置管理の考え方です
（指摘 → 是正 → 検証 → クローズ）。

## 情報の区画

医療に関わる情報は、医師のみが扱う区画に分かれています。
会社の画面に表示されるのは、判定・措置・期限・記録——
就業上の判断に必要な情報だけです。

## 記録が、そのまま説明になる

面談・意見・決定・実行・見直しの全工程が、日時つきで残ります。
監督署の調査や係争の場面で問われるのは「実施したか」ではなく
「何を確認し、どう判断し、どう見直したか」です。
Casetraの記録は、その問いにそのまま答える形で残ります。

## 4. クリニック側への1行提案（先方リポジトリ・todo「着手待ち④ /self-pay/ 書き直し」向け）

自費ドックの使用場面に、個人向け・本人起点のユースケースとして次の趣旨を
1行加えることを提案する（文言は先方の文体に合わせる）:

```
復職を控えて、生活リズムが出勤時刻に合っているかを客観的に確認して
おきたい方。結果レポートは、ご自身から会社や産業医に提出いただけます。
```

- 無症状・希望ベース・本人申込みなのでクリニックの振り分け原則
  （症状→保険／無症状→自費ドック）に適合
- 矢印はクリニック→個人→（本人の意思で）会社。事務所・会社からの
  手配ではないため、受診手配禁止の方針とも矛盾しない
- 事務所側の「休職・復職判定支援」ページはデータの受け入れ仕様だけを
  書き、機関名は書かない（§1-3）。両サイトの整合はこの分業で保つ
