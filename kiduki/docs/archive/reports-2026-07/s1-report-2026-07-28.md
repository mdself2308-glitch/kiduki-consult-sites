# S1 止血レポート

作業日: 2026-07-28

## 実装内容

- `reserve/index.html` の旧事前ヒアリングフォームを非表示にした
- 進捗表示と所要時間表示を非表示にした
- 削除済みAzure FunctionのURLを除去し、API送信を無効化した
- API失敗時の `localStorage` 保存処理と偽の成功表示を除去した
- 隠れた旧フォームから送信処理が呼ばれた場合も、送信・保存・成功表示を
  行わず、移行案内へフォーカスを戻すようにした
- 指示書指定の文言と `mailto:` リンクを表示した

表示文言:

```text
現在、お問い合わせ窓口を移行しています。
恐れ入りますが、下記メールアドレスまで直接ご連絡ください。
info@kdkconslt-sngyouijm.com
```

## 確認結果

- PC幅 1440×900: 表示正常、横方向の見切れなし
- スマホ幅 390×844: 表示正常、メールリンクが画面内、横方向の見切れなし
- 最小確認幅 320×812: メールリンクが画面内、横方向の見切れなし
- 旧フォーム、進捗、所要時間: すべて `display:none`
- ブラウザのエラー・警告: なし
- `localStorage`、旧Azure Function URL、偽成功メッセージ: ソースから除去済み
- `npm run verify`: 成功
- `npm run verify:static`: 成功

## 公開状態と残件

- この変更はローカル実装まで。`main` にはpushしていないため本番未反映
- `main` へのpushは両Azure Static Web Appsをデプロイするため、全同乗差分を
  提示して明示承認を得てから実行する
- WordPress `/question/` は本番書き込みの承認ゲート対象のため未変更。
  現在は旧Azure相談ページへのリンクが残っている。S1で同じ移行案内へ
  差し替える場合は、WordPressの変更前バックアップとdry-runを提示してから
  別途承認を得る
