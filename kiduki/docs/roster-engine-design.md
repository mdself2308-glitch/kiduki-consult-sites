# ロースターエンジン 設計原則

確定: 2026-08-02 ／ 対象: 健診・SC・教育の名簿型業務
原理: 「当社がやる」ではなく「当社のシステムが実施し、企業はダッシュボードで見る」

## なぜシステム吸収が事業要件か

- 人力督促は労働集約＝仲介業者と同じ構造に堕ちる
- 売却ストーリーの根拠数字は「工数/顧客の逓減」。人力で吸収した瞬間に崩れる
- 限界費用ゼロの督促だけが、価格カード（込み件数＋超過）の粗利を支える

## 自動化の3層

| 層 | 実行者 | 中身 |
|---|---|---|
| システム完全吸収 | Casetra | 対象者判定（定期・雇入時・特定業務6ヶ月・海外派遣のルール）／段階リマインド（期日接近→超過エスカレーション）／センターCSV突合（受診状態の自動判定）／進捗ダッシュボード／帳票生成 |
| 会社へワンクリック委譲 | 会社（システムが通知） | 最終未受診者への受診指示＝**業務命令＝人事権**。上司・人事へ「この◯名に声かけを」を自動通知。bpo-scope-boundary.md の「実行は会社」と一致 |
| 残る人力（最小化） | MedSelf運用 | AI抽出の低信頼分の検証のみ（転記は消え、検証が残る） |

## ダッシュボード＝証跡

企業側ポータルの「受診率・未受診者・督促ログ」は進捗表示であると同時に
**「会社は勧奨を尽くした」記録**（安衛法66条5項の履行証跡）。
根幹テーゼ3問を通過：健診事後の空白／証跡が残る／命令の決定は会社。

## 実装の正体（ゼロから作らない）

- `portalCompanyDashboard` 実装済み（企業側ポータルの器）
- `bookingReminderAndMonitorTimer` 実装済み（リマインドのタイマーパターンを転用）
- SER-HEALTHCHECK の roles_sequence で `role: hr` の2工程
  （seq20 名簿維持 / seq40 督促・回収）を **`role: system` に昇格**させる
- 新規開発: 従業員マスタ（HR側CSV同期）／対象判定ルール／
  従業員単位の受診ステータス／一括リマインド配信／ダッシュボード画面

## 設計判断（開発前に決める）

- [ ] リマインドの送信者名義: 会社名義（顧客ごとにSPF/DKIM設定）か
      中立名義か。従業員に無視されない送信者設計が自動化の成立条件
- [ ] データ区画: 受診の**有無**（労務管理情報）と受診**結果**（要配慮）を
      分離し、ダッシュボードは前者のみ表示（人事全員に見せられる）
- [ ] エスカレーション段階の既定値: 例）受診期限14日前→本人通知、
      7日前→再通知、超過→本人＋上司、2週間超過→人事ダッシュボードで要対応表示

## 営業上の位置づけ

ダッシュボードは**デモできる価値**。センター訪問・既存顧客転換・記事の
スクリーンショットの中心素材。ロースターエンジン完成が営業資料の完成を兼ねる。

## 結果回収の3レーン（2026-08-02 追記：転記人力の解消）

| レーン | 状況 | 動線 |
|---|---|---|
| A | センター連携あり | CSV連携（最優先・写真不要） |
| B | 非連携機関・会社一括納品 | 人事が一括スキャン→アップロード→AI抽出 |
| C | 本人の手元（個人受診・雇入時持参・**二次検査**） | **本人撮影アップロード**（Todoから認証付き・期限付きリンクを発行。portalBoxEvidenceLinks 転用） |

- 全レーンが同じ**検証キュー**に着地。AI抽出値は「未確認」で入り、
  低信頼のみ原本画像と並置して医師/運用が確定（誤OCRを意見書に乗せない）
- 公開URLの共有フォルダは不可。必ず本人単位のトークンリンク
- 本人提出は本人同意が行為に内蔵される（生データ→医療区画、会社→判定のみ）
- 未提出は未受診と同じステータス管理＝同じ督促エンジンで追う
  （自主受診の結果証明書提出は安衛法66条2項の本人義務——案内文に明記できる）

## 対象除外キュー（2026-08-02 追記：グレー判定の会社委譲）

- システムが検知（督促バウンス・HR CSVの休職フラグ・無応答）→
  会社ダッシュボードに**提案つきタスク**「この◯名を対象から除外しますか」
- 会社がワンクリック確定。除外理由はプルダウンで構造化
  （退職／休職／海外派遣／産休育休／短時間／その他）
- **除外は「解除条件つき措置」と同型**：再対象化条件を必ず付ける
  （休職除外→復職日入力で自動的に対象復帰タスク）
- 除外記録は労基署対応の証跡（「なぜ未受診か」に判断者・日付つきで即答）

## 一般原理

**事実を持っている者に、ワンクリックだけを返す。**
本人は自分の結果を、会社は自分の人事情報（決定・提出・声かけ・除外確認）を、
医師は判断を。それ以外の全部をシステムが運ぶ。
