# 事業原理（コア・テーゼ）

確定: 2026-08-01 ／ 出典: 2026-07〜08 の戦略検討 ／ **本書がこの事業の根幹**

## 原理

**法制度が作った「判断と実行の空白」を、証跡つきで受け止める。**

- **復職判定の空白** — 主治医の診断書と職場の間に翻訳者がいない。
  医学を知らない人事に、決定責任だけが落ちる
- **措置解除の空白** — 措置には期限と解除条件が要るのに、期限を追う
  仕組みが誰にもなく、制限が永久化する
- **高ストレス放置の空白** — 面談申出は数%・結果は本人止まり。
  制度は気づかせて、放置する

**制度が欠陥を持ち続ける限り、市場が補充され続ける。**

## なぜこの形が成立するか

1. 産業衛生の義務は**手続き義務**であり、決定権は法が事業者に固定している
   （安衛法66条の4・66条の5等）。受託者が結果責任を負わない構造が法文レベルで
   担保されている——税務アウトソーシングが成立しない理由の、正確な裏返し
2. **手続きを確実に回して記録した事実そのものが、会社の法的防御になる。**
   税務では完璧に文書化された誤った判断は救われないが、産業衛生では
   記録が防御になる。証跡はオプションではなく商品の本体
3. 空白を埋める行為（判断・追跡・証跡）は、ソフトウェア＋医師の判断層で
   標準化できる。仲介（人を置くだけ）にも、健康管理SaaS（データを溜める
   だけ）にも、構造的に真似できない

## 新商品・新機能・新記事の判定基準（3問）

次の3問に通ったものだけ作る。

1. **どの制度の、どの空白を受け止めるか**
2. **証跡が残る形か**（「やった」を「証明できる」に変えるか）
3. **決定権が事業者に残る設計か**（決定クリック・提出クリック——法の壁を
   契約書ではなくソフトウェアの仕様で守る）

## 棚の規律（並んではいけない場所）

- **健康管理システムの棚**（Carely等）— 彼らの管理単位は従業員×データ、
  こちらは案件×完了。健康データ系の語（一元管理・見える化・ウェルビーイング）
  を使わない
- **EAP・リワーク・メンタルヘルスケアの棚** — 「ケア」「カウンセリング」
  「寄り添う」を使わない。使う語は判定・措置・解除条件・証跡
- **格安産業医の棚** — 価格で並ばない。比較の分母は看板価格ではなく
  真の総コスト（隠れ工数込み）、比較の相手は「専任者を1人雇う場合」
