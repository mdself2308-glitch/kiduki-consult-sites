# 産業衛生アウトソーシング 責任分界（境界定義）

確定: 2026-08-02 ／ 用途: 契約書別表の原型・営業説明・センター向け説明の元
原理: core-thesis.md の第3問「決定権が事業者に残る設計か」の全業務への展開

## 境界は3本

```
① センターとの境界   「実施まではセンター、結果の後は当方」
② 企業との境界       「実施と証跡は当方、決定と実行は会社」
③ 医療との境界       「評価と意見まで。診断と治療はしない」
```

## ② 企業との境界（本体）

### 当方が請け負う範囲（実施・段取り・記録・意見）

**健診運用**
- 年間計画案の作成、対象者名簿の維持（会社提供のHRデータに基づく）
- 予約調整・枠管理、未受診者への督促、結果回収とデータ化
- 有所見者の抽出、医師の意見聴取（安衛法66条の4）
- 事後措置の段取りと追跡、再検査勧奨と受診確認
- 帳票生成（定期健診結果報告等。提出は会社のワンクリック）

**ストレスチェック**
- 実施者・実施事務、受検勧奨、高ストレス者の面談勧奨・面接指導
- フォロープログラム（全員同一内容・3層動線）、集団分析、報告書生成

**長時間労働**
- 勤怠データ（会社提供）からの対象抽出、申出勧奨
- 面接指導（オンライン。要件は年1回訪問で維持）、意見書＋措置4点セット

**復職・両立支援**
- 復職案件パック一式（照会状・面談3回・意見書・措置4点・Decision Pack）

**衛生委員会・教育**
- 年間議題案・資料・議事録案の作成（事務局代行）、選任時は出席
- 安全衛生教育の資材提供・研修講師

**記録・証跡**
- 5年保存の管理、証跡チェーン、監査・調査時の資料出力

**巡視**
- 選任時は法定頻度。非選任時は年1回（オンライン面接指導の要件維持）

### 会社に必ず残るもの（法が事業者に固定・外注不能）

1. **安全配慮義務の主体**であること（労働契約法5条）
2. 就業上の措置の**決定**（安衛法66条の5）→ Casetraの決定クリック。
   決定が記録されない限り案件はクローズできない仕様
3. 措置の**実行**＝人事権の行使（残業制限の業務命令・配置転換・休職発令）
4. **衛生管理者の選任**（社内の労働者から。当方は選任手続きの支援まで）
5. 衛生委員会の**設置・開催主体**（当方は事務局）
6. 官庁への**提出行為**（Casetraが帳票生成、会社がワンクリック提出）
7. 就業規則・社内規程の制定改廃（当方は案文提供まで）
8. 労働時間・勤怠の管理そのもの（データは会社が生成し当方へ提供）

### 対象外＝企業案件（当方は証跡提供と健康面の意見で支援するのみ）

- 懲戒・人事処分・解雇・退職勧奨の判断と実施
- ハラスメント等の**事実調査**（調査主体は会社・弁護士。当方は関係者の
  健康面対応と記録のみ）
- 労使交渉・訴訟の当事者対応（弁護士領域。当方はDecision Pack等の証跡提供）
- 賃金・評価・異動などの労務管理一般
- 狭義の労働「安全」＝機械・設備の安全対策の実行
  （作業環境測定の手配・記録は運用として請けるが、改善工事等の実行は会社）
- 従業員の私生活・家族への対応
- 診断・治療（医療機関へ。受診先は本人が選ぶ・複数選択肢）

### 灰色事案のエスカレーション規則

| 事案 | 扱い |
|---|---|
| 係争化・弁護士介入 | 月額・パックの対象外へ切替（紛争対応スポット ¥200,000〜）。役割は証跡提供＋健康面の意見に限定 |
| 懲戒と健康の交錯（勤怠不良が疾病由来か等） | 当方は「疾病性の評価」まで。処分判断は会社 |
| 自傷他害等の緊急 | 緊急対応（×1.6）で医療接続。以後の労務判断は会社 |

## ① センターとの境界

- 健診の**実施**（検査・判定）はセンター。当方は一切やらない・奪わない
- 結果が出た**後**（データ化・有所見対応・意見聴取・措置・記録・報告）は当方
- センター向けの一言:「**健診の"後"を全部やる会社です**」

## ③ 医療との境界

- 当方が行うのは**評価と意見**（就業判断の材料づくり）まで
- 診断・治療は医療機関。受診先は本人が選ぶ（複数選択肢・関係開示）
- アクチグラフ等は非医療の評価器具として運用（診断しない）

## 契約文言への落とし込み

- 当方の債務は「**プロセスの実施と証跡の提供**」（手段債務）
- 決定と実行の責任は事業者に留保（本表を契約書別表として添付）
- 賠償上限・保険は open-items.md の事業設計項目を参照
