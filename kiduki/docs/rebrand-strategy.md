## 1. ポジショニング

**現状診断**
- 現サイトの旗「東京の産業医契約なら」= 乱立市場のコモディティ検索で価格比較される位置
- トップが抽象的な理念中心で、誰の何の問題を解くのかが最初の3秒で伝わらない
- 差別化要素「心療内科専門医の知見×メンタルヘルス」は、精神科特化事務所が多数いる激戦ポジション

**新ポジション**
- **「働く人の睡眠に特化した産業医事務所」**
- 原則: 「睡眠しかやらない産業医」ではなく**「睡眠を旗にした、フルスペック産業医」**。法定業務(衛生委員会・職場巡視・面接指導・休復職判定・ストレスチェック)は全対応。特化するのは看板・商品ライン・選ばれる理由
- 睡眠がメンタルより強い旗である理由: ①不眠はメンタル不調の最初のサイン=**上流**から同じ市場を取れる(メンタル特化勢と正面衝突しない) ②安全(居眠り・労災・SAS)、生産性(睡眠不足の経済損失)、健康経営(認定調査項目)という**経営者が財布を開く3つの言葉**に直結 ③「睡眠特化の産業医事務所」は検索上ほぼ空白

### 【2026-07-28 追記】健康経営制度における睡眠の格上げ — 一次資料で確認済み

**この旗を今立てる根拠が、制度側で急速に強まっている。**以下はすべて一次資料で確認した事実。

**① 現行(令和7年度)の健康経営度調査に、すでに睡眠設問が存在する**

中小規模法人部門 **Q42**(大規模法人部門 **Q56**)「従業員の生産性低下防止のために、どのような取り組みを行っていますか」
＜a．睡眠障害や、業務中の眠気による生産性の低下予防＞の選択肢:

1. リフレッシュルームや仮眠室を設置している
2. パワーナップ等仮眠制度を導入している
3. **睡眠に関するセミナーを実施している** ← 睡眠研修パッケージが直接該当(中小規模版のみの選択肢)
4. SAS検査を実施している(費用補助を含む)
5. 睡眠改善に関連するアプリ等を利用できるようにしている
6. **産業医等による睡眠関連指導を実施している** ← **事務所と契約すること自体が企業の加点行為になる**

> 選択肢6が営業上の最重要材料。調査票が「産業医等による睡眠関連指導」を名指ししており、
> **睡眠に強い産業医と契約すること自体が、企業が調査票に回答できる取り組みになる**。提案時に必ず示す。
> なお主要ターゲットの50〜300名は**中小規模法人部門**にあたり、選択肢3(睡眠セミナー)が独立して存在する。

**② 経産省の公式記入例が睡眠セミナーである**

中小規模法人部門の申請内容記載表に印刷されている記入例②(原文):
- 課題「睡眠不足・不眠症のために日中の眠気を訴え仕事に集中できない社員が3割程度存在している」
- 数値目標「睡眠不足・不眠症に悩む従業員の割合 30% → 15%」
- 計画「全従業員を対象に睡眠セミナーを開催」

→ 営業トーク:**「経産省が申請書の書き方の見本として挙げているのが、まさに睡眠セミナーです」**(誇張ではなく実物にそう書いてある)

**③ 令和8年度から「睡眠の質向上に向けた取組」が独立設問に新設される方針**

第6回健康経営推進検討会 事務局資料(2026年7月14日・経産省ヘルスケア産業課)より。
令和7年度は「生産性低下防止への施策(睡眠、肩こり・腰痛、飲酒、花粉症…)」の一部だったものが、
令和8年度案では**独立したQとして分離**され、生産性低下防止の側から睡眠が抜ける。

同資料が挙げる背景:
- **骨太の方針2026(原案)に「睡眠対策を含む健康経営の推進」が明記**
- 2026年3月、睡眠関連2業界団体が連名で業界自主ガイドラインを公表
- **2026年6月より医療機関が「睡眠障害」を診療科名に使えるようになった** ← 睡眠障害内科を掲げる制度的裏づけができたのは2か月前

**④ 経産省が公表するテーマ別ベストプラクティス5テーマの③が「睡眠の質向上に向けた取組」**

大企業10社・中小企業40社を選定し、取り組み概要と審査員コメントを経産省が資料化して公表予定。
厚労省の普及啓発事業との連携も検討中。**支援先が選ばれれば国の公表事例に事務所の仕事が載る** = 実績ゼロからの最短の信用構築経路。

**⑤ タイミング** — 令和8年度健康経営度調査の実施は**令和8年8月〜10月**。企業が申請準備に入るのは目前。

> **表現上の注意**: ③④は「案」の段階。確定版調査票の公表まで「新設されます」ではなく
> **「新設される方針が示されています」**と書く。確定後に表現を更新する。
>
> **認定要件と調査票を混同しない**: 認定要件(①〜⑰の一覧)には睡眠という名称の項目は**ない**。
> 睡眠設問があるのは企業が実際に記入する**調査票**の側。営業では調査票を根拠にする。
- 理念の接続(改名不要): 事務所名・「気づき」の理念はそのまま、**「不調の最初の気づきは、眠りに現れる。」**の一文で睡眠特化と接続する
- タグライン案: 「眠りから、職場の安全と生産性をつくる。」
- 名乗り規律: 「睡眠専門医」は名乗らない・示唆しない(全体設計図の共通規律に従う)。表記は「内科専門医・心療内科専門医・労働衛生コンサルタント/睡眠障害内科 院長」

## 2. ターゲット

**業界の優先順位**
1. **運輸・物流**: SAS対策(国交省がスクリーニングを推奨するマニュアルを公表)、2024年問題、健康起因事故。法的・社会的圧力が最も明確な beachhead
2. **製造(交代勤務)**: シフト勤務の眠気×労災、夜勤者の健康管理
3. **医療・介護**: 夜勤者の離職・休職対策
4. **IT・専門職**: 長時間労働×不眠×メンタルの複合

**買い手ペルソナ**
- 従業員50〜300名企業の人事総務(産業医選任義務はあるが「名義だけ」の形骸化に悩む/健康経営認定を取りたい)
- 運輸業の安全管理部門(事故ゼロが至上命題)
- 既に産業医はいるが、研修・スポット施策だけ外部に出したい大手

**Casetra との関係(2026-07-28 確定)**

自社開発の産業保健オペレーションシステム Casetra は `casetra.jp` で稼働中(3ポータル/2026年7月ローンチ)。
事務所サイトで**商品として売らない。1ブロック+リンクに留める**。理由:

- Casetra には自前のサイトがあり、事務所サイトで機能説明をする必要がない
- 事務所(人が提供するサービス)とCasetra(プロダクト)は別事業。1枚のページで両方売ると、どちらの会社か分からなくなる
- 現に静的トップの18セクション中8セクションがCasetraの機能説明に費やされ、睡眠の旗が入る余地を失っている
- **Casetraをリンクに落とすと、その8セクションを1ブロックに畳む正当な理由ができる**。ページはむしろ簡潔になる

ただしCasetraは**要配慮個人情報を扱う**。曖昧な紹介は「相談したら健康情報がどこへ行くのか」という不安を生むため、
「運用はCasetraで回します」と明示し、詳細は `casetra.jp` へ渡す。

**層3: 上流商品** — 労働衛生コンサルタント顧問/講演/執筆・メディア監修

**堀: クリニックとの垂直統合**
- 見つける(スクリーニング・研修)→設計する(コンサル)→治す(睡眠障害内科)→職場に戻す(産業医)。医療機関を持たない紹介会社・他事務所には構造的に真似できない
- ガードレール: 受診先は常に「選択肢の一つ」として提示/同一労働者で産業医と主治医を兼ねる場面の情報分離・本人同意ルールを文書化

**価格設計の原則**
- 時間売り(月◯回訪問◯万円)ではなく成果物売り(報告書・アセスメント・年次運用)。パッケージは比較されない
- 参考の相場帯(**契約前に地域相場・稼働で必ず再確認**): 嘱託産業医は企業規模により月数万〜十数万円/医師の企業研修は1回十数万〜数十万円が一般的な帯。睡眠付加価値+報告書付きで帯の上位に設定し、値引きではなく提供範囲で調整
- 初回の入口は研修(単発・高粗利・意思決定が速い)→信頼→嘱託・顧問へ上がる「はしご」
- **睡眠研修の具体的な価格は2026-07-31時点で保留**。サイト上は全サービスとも金額を出さず
  「お問い合わせ」で統一する。金額を出す判断をした時点で本節と site-copy.md を先に更新すること

## 4. メッセージング(トップページの語り順)

1. **問題提起**: 居眠り事故・夜勤者の休職・「健康経営の睡眠項目、何をすれば?」——読者の言葉で
2. **数字**: 睡眠不足の経済損失(国内で年間十数兆円規模との試算)/未治療のSASの事故リスク上昇(数倍との報告)など ※**公開前に一次資料を確認し「〜との試算」「〜と報告」の表現で。断定しない**

4. **商品3つ**(研修/SAS/コンサル)+嘱託産業医
5. **代表者**: 三資格+睡眠障害内科 院長という実在の臨床医(物語は「なぜ睡眠か」)

**禁止表現**: 効果保証/「睡眠専門医」/顧問先従業員への受診誘引/根拠を確認していない数字

## 6. 問い合わせページの統合(Azure Static Web Apps → WordPress)

**方針: 統合する。** 理由: ①B2Bは問い合わせ直前が最も慎重——別ドメインのフォームは不信で離脱を生む ②GA4のコンバージョン計測がドメイン跨ぎで崩れ「どの記事が受注を生んだか」が見えなくなる ③保守二系統は一人経営では必ず片方が放置される

**新フォーム設計(リード選別を仕込む)**
- 項目: 会社名/業種(選択式)/従業員数(帯)/相談種別(睡眠研修・SAS対策・交代勤務コンサル・嘱託産業医・顧問/講演・取材・その他)/内容/氏名・連絡先
- スパム対策: Cloudflare Turnstile(reCAPTCHAよりUX良)
- 自動返信メール+通知先設定。送信完了は専用サンクスページへ遷移(**ここをGA4コンバージョン計測点にする**)
- **メール送信は旧Azureフォームの送信資産を流用する**: SPF/DKIMは「ドメイン×送信サービス」に紐づく資産なので、WordPressから同じ送信サービス(SendGrid/ACS/M365等)経由で送れば、DNS設定・配達実績・送信元の評判をそのまま引き継げる(詳細手順はPhase 1作業指示書 T0-2/T2-2)
- 個人情報: SSL必須/プライバシーポリシーへの同意チェック/通知メールに機微情報を平文で流さない運用
- 連絡手段の方針: **電話番号はサイトに掲載しない**。フォーム+直通メールの二本立て(フォーム障害時のフォールバックはメール)

**移行手順(Codexで1日)**
1. WordPress側に新フォームページ公開(URL例: `/contact/`)
2. 旧Azure側: `staticwebapp.config.json` の `routes` で新URLへ**301リダイレクト**を設定
3. リンク元の総点検・差し替え: 名刺QR/メール署名/Googleビジネスプロフィール/note/クリニックサイト/SNSプロフィール/過去記事内リンク
4. 2〜4週間の並行期間(リダイレクトのアクセスログで旧URL流入が消えたことを確認)
5. Azure Static Web Apps を停止・リソース削除(カスタムドメインを充てていた場合はDNS整理)

## 7. WordPress実装仕様(Codex運用の前提ルール)

**環境と安全網**
- 子テーマを作成しGit管理(親テーマ・プラグイン本体の直接編集は禁止)
- 変更は必ず「バックアップ→ステージング→本番」: バックアップはDB+ファイル一式(UpdraftPlus等)。ステージングはホスティング付属機能またはローカル(wp-env)
- Codexへの作業単位: 1タスク=1コミット。`functions.php`・`style.css`・テンプレートの変更はコミットメッセージに目的を明記
- 記事入稿はWP-CLIまたはREST APIで可(Markdown→ブロック変換)。下書き投入→先生が管理画面で最終確認→公開

**プラグイン最小構成(10個以内厳守)**
- SEO(1つだけ)/フォーム(Contact Form 7等)+Turnstile連携/キャッシュ・高速化/画像圧縮(WebP)/バックアップ/セキュリティ(ログインURL変更+2要素認証)
- 使っていないテーマ・プラグインは削除。自動更新はマイナーのみ有効、メジャーは手動

**構造化データ**
- Organization または ProfessionalService(名称・住所——GBPと表記一致。**電話番号はサイトに掲載しない方針のため telephone プロパティは省略**)/Service(商品4つ)/Article(著者=代表者+資格表記)/FAQPage
- **MedicalClinicは使わない**(事務所は医療機関ではない。医療機関性の演出はしない)

**品質基準**
- モバイル最優先・表示速度(不要スクリプト削除・画像最適化)
- 全ページ: タイトルタグ・meta description・OGP・パンくず
- 計測: GA4+Search Console。コンバージョン=サンクスページ到達。月次で「記事別→問い合わせ種別」を確認
- 法務: プライバシーポリシー/事務所概要の正確表記(代表者・資格は統一表記)/サービスを直販する場合は特定商取引法表記の該非を確認

## 8. KPIと営業のはしご

- KPI: 問い合わせ数(種別別)/研修受注数/嘱託・顧問契約数/「事務所名 産業医」「睡眠 産業医」指名・関連検索/note→サイト流入/記事別コンバージョン
- はしご: 記事・note→問い合わせ→**研修(単発・高粗利・即決)**→嘱託産業医→顧問
- 産業医紹介会社経由は価格競争になるため主戦場にしない。コンテンツ経由の**指名**で来る構造を作る(これが乱立市場からの唯一の出口)
