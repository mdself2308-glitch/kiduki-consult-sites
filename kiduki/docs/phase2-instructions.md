### R10: パフォーマンス・OGP・構造化データ

**10-1. 予約用GIFの軽量化（0-7）**

現状 `consult/予約用.gif` が 5,480,744 bytes（5.48MB）。`consult/` の中身は `index.html` とこのGIFの2ファイルだけであり、**ページ総重量のほぼ全てがこの1枚**である。

  - **推奨**: 静止画（WebP、JPEGフォールバック）+ 説明キャプションに置き換える。予約画面は動きが本質ではない
  - 動きを残す場合は MP4（`<video autoplay muted loop playsinline preload="none">`）に変換。**GIFのままにはしない**
- **同時にファイル名をASCIIへ変更する**（例: `booking-preview.webp`）。現在の日本語ファイル名は URL で `%E4%BA%88%E7%B4%84%E7%94%A8.gif` とパーセントエンコードが必要で、外部ツール・CDN・ログ解析で扱いを誤りやすい。旧ファイルは削除せず、置き換え完了と本番表示確認までリポジトリに残す
- `loading="lazy"`・`width`/`height` 属性を明記（レイアウトシフト防止）
- 変更後のファイルサイズと、`index.html` からの参照が更新されていることを報告

**10-2. キャッシュヘッダー（0-7）**

`cache-control: max-age=30` は Azure Static Web Apps の既定値である。**`consult/staticwebapp.config.json` は現在存在しない**（`consult/` には `index.html` とGIFのみ）。したがって**新規作成**する。

**安全上の注意**: このファイルは本番トップのルーティングを左右する。**`routes` と `navigationFallback` は書かない。** ヘッダー指定のみに限定し、リダイレクトやリライトを一切追加しないこと。

作成する内容（これをそのまま使う。10-1で決めた実際の拡張子に合わせる）：

```json
{
  "trailingSlash": "auto",
  "routes": [
    {
      "route": "/*.{png,jpg,jpeg,webp,gif,mp4,svg,ico,woff2}",
      "headers": {
        "cache-control": "public, max-age=31536000, immutable"
      }
    }
  ]
}
```

- HTML には長期キャッシュを付けない（デプロイが反映されなくなるため）。上記は**画像・動画・フォントのみ**が対象

- push前に、この設定ファイル追加によって**トップページ・GIF・`/contact/` へのCTAがすべて従来どおり動くこと**をローカルまたはプレビュー環境で確認する

  - `curl -sI https://consult.kdkconslt-sngyouijm.com/` → HTMLは短命のまま（`max-age=30` 相当）
  - 画像URL → `max-age=31536000` が付いていること

## 9. 禁止事項（Phase 1 から継続。違反した場合は作業をやり直す）

- **明示承認のない `main` への push**（両Azure Static Web Appsがデプロイされるため。毎回差分提示→承認）
- 親テーマ・プラグイン本体・WordPressコアの直接編集（カスタマイズはすべて子テーマ内）
- 本書指定以外のプラグイン追加／既存ページ・記事・画像の削除
- **`docs/copy/` 配下の確定文言の改変** — 改善案は実装せず「提案」として報告する
- **付録Aの【】を推測で埋めること**（「未記入可」と明記した箇所を除く）
- **数値・統計の新規追加**（一次資料を確認し「〜との試算」「〜と報告」の形にしたうえで、別途承認を得る）
- **「海運会社」を顧問先・契約先の実績として掲載すること**（雇用契約〈週3日勤務〉であり顧問先ではない。表記は「運輸」に留める。詳細は 0-12）
- 提供実体のない商品を掲載すること（0-11。掲載する商品ラインは院長の承認を得てから確定する）
- 顧問先の**企業名**の掲載（許諾なしの実績開示にあたる。業種名までに留める）
- 「睡眠専門医」「睡眠の専門医」の使用。効果の断定・保証。顧問先従業員への受診誘引にあたる表現
- **電話番号のサイト掲載**、および構造化データへの `telephone` 追加
- 構造化データへの `MedicalClinic` の使用、医療機関性の演出
- 無承認でのDNS変更。Azure SWAのカスタムドメインを支えるレコードへの一切の変更
- `reserve/staticwebapp.config.json` の301設定の破壊（Phase 1 T4の成果物）
- APIキー・接続文字列・パスワード類のコミット・画面表示・ログ出力
- WordPress への書き込みをスクリプト以外（管理画面手動・生API直叩き）で行うこと。書き込みは必ず dry-run → バックアップ → apply の順
