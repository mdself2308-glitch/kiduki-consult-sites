# 健診センター連携 要求仕様（持参用1枚ドラフト）

状態: ドラフト（センター名・先方システム名を記入すれば持参可能）
目的: 当方が企業から受託する健診の「運用」（予約突合・未受診督促・
結果回収・事後措置）を回すためのデータ連携。

## お願いしたいこと（3点だけ）

**1. 結果データの電子出力（CSVまたはAPI）**
- 対象: 当方が運用を受託する企業の受診者分のみ
- 項目: 受診日／法定項目の結果値／判定区分（貴センター基準）／要再検・要精査フラグ
- 形式: 列仕様を固定したCSV（仕様変更時は事前連絡）。頻度は週次または月次

**2. 予約・受診状況の定期リスト（週次）**
- 予約済・受診済・キャンセルが分かる一覧（氏名・所属企業・受診日）
- 用途: 当方の対象者名簿と突合し、未受診者への督促を当方が実施

**3. 判定区分の定義書**
- 貴センターの判定基準一覧（産業医の就業判定の入力として扱うため）

## 貴センターのメリット

- 未受診者の督促を当方が担う → **受診率の向上・年度内の消化**
- 事後措置まで回る → 企業の満足・契約継続
- 当方の受託企業のうち健診機関が未定の先を貴センターへご紹介
  （非独占の優先枠。既存の健診機関がある企業はそのまま）

## 個人情報の建て付け

- 企業 → 当方: 産業保健業務の委託契約（要配慮個人情報の取扱いを含む）
- 貴センター → 当方: 企業の委託先間の受け渡し（第三者提供に当たらない構成）
- 授受はセキュアな経路（SFTP等）で行い、記録を双方保存
