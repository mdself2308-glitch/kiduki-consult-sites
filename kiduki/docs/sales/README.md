# KIDUKI・CASETRA 営業資料

更新: 2026-08-06（v2 全面改訂）

## 使い分け

- `KIDUKI_service_guide_202608.pdf`（10頁）: 産業医サービス全般の案内。産業医の法定業務一覧（法令根拠つき）→休職・復職の専門性→復職支援Pack・Basic・Retain→契約者料金→情報管理→FAQの順。休復職相談だけでなく、嘱託産業医の新規相談にも送付できる
- `CASETRA_platform_guide_202608.pdf`（8頁）: 自社の人事・産業医等でCaseを運用する企業向け。「産業医事務所が自らの実務のために開発した」という来歴を最初に説明し、機能→料金（含まれる/含まれないを明示）→医師業務が必要な場合の2パターン→導入の流れ
- `.pptx`: 面談先に合わせて表紙や一部説明を調整するための編集用正本（フォント: ヒラギノ角ゴ ProN／明朝 ProN。macOSのPowerPointでそのまま編集可）
- `website-pricing-audit-2026-08-06.md`: 公開サイト、料金正本、CASETRA実装の整合確認記録
- `archive/202608_v1_旧版/`: 改訂前の旧資料（参照用）
- `generator/`: 資料の生成スクリプト（pptxgenjs）。文言・レイアウトを大きく作り直す場合は `node kiduki.js` / `node casetra.js` → `python3 fix_ea_fonts.py <pptx>` で再生成できる

## v2 改訂の要点（2026-08-06）

1. **KIDUKI資料からCASETRAの売り込みを削除。** システムには「当事務所の業務運用の一部・貴社に追加のシステム利用料は発生しません」として1か所だけ触れる（FAQに独立契約の案内1問）
2. **「二重請求しない設計」等の内部用語を全廃。** 顧客向けには「料金は事前にすべてご提示します」（3つのお約束）として肯定形で記載
3. **一般産業衛生業務への対応を明記。** 衛生委員会・職場巡視・健診事後措置・長時間労働面接指導・ストレスチェック・健康相談等を法令根拠つきで一覧化（公開サイトFAQ「睡眠に特化しているとのことですが、通常の産業医業務も頼めますか？→対応します」と整合）
4. トーンを売り込み型から信頼形成型へ（基本姿勢・健康情報の取扱い・「その場でのご契約は不要です」等）

## 料金変更時の規律

営業資料の料金を直接先に変更しない。必ず次の順に更新する。

1. `../pricing-growth-canonical.md`
2. CASETRA料金マスター・請求ロジック
3. 契約書・見積書テンプレート
4. 公開サイト
5. 本フォルダのPowerPoint・PDF

KIDUKI月額契約企業の復職案件では、客観評価、機器・物流、Decision Pack等のTechnical Operations SKUが未確定である。この部分の総額を、確定前に営業資料や公開サイトへ固定表示しない（現行資料は非契約企業向けPack 150,000円のみ記載で、この規律に適合）。

## PDF再生成について

送付用PDFはNoto Sans/Serif CJK JPを埋め込んで生成している（環境に依存せず表示が安定）。ヒラギノ版のPDFが必要な場合は、PowerPointで.pptxを開き「PDFとして保存」で書き出す。
