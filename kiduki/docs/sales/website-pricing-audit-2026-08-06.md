# KIDUKI・CASETRA 公開料金整合監査

確認日: 2026-08-06

料金正本: `../pricing-growth-canonical.md`

## 結論

- **KIDUKI公開トップ**: 具体額を出さず、契約範囲確認後に概算を示す方針。現行正本との数値矛盾なし。
- **CASETRA公開トップ**: STARTER 40,000円、STANDARD 60,000円、PLUS 99,000円、Case・予約枠と各超過単価は正本・実装と一致。
- **要修正**: `https://casetra.jp/service/sample-service3/` が現在もHTTP 200で公開され、旧料金を表示している。公開トップ・料金正本と明確に矛盾するため、更新、非公開化、または現行トップ料金への301転送が必要。
- **商品境界の要修正**: `https://kdkconslt-sngyouijm.com/service/spot/` は金額を固定表示していないが、「1回対応」の一般的なスポット商品を案内している。正本では一般SPOTを廃止しているため、復職支援Pack等の固定商品へ書き換えるか、公開停止を検討する。

## 1. KIDUKI公開サイト

### 静的トップ

- 公開URL: `https://consult.kdkconslt-sngyouijm.com/`
- ローカル正本: `consult/index.html`
- 確認結果: 公開HTMLとローカルHTMLは完全一致
- 公開文言: 企業規模、訪問頻度、委員会頻度、相談範囲を確認後に概算提示
- 具体的な料金数字: なし
- 判定: **数値矛盾なし**

検索エンジンには過去の「4万円台〜」が残る場合があるが、2026-08-06時点の公開HTMLには存在しない。

### WordPress下層

公開固定ページの料金数値を抽出したところ、事業料金として固定額は見当たらなかった。プライバシーポリシーの開示手数料1,000円はサービス料金ではない。

ただし、スポット産業医ページは以下を表示している。

- 「1回対応ごと。詳細はお問い合わせください」
- 個別従業員面談・健康相談は対象外
- 産業衛生体制構築、健康経営相談、統計分析を単発対応

金額の矛盾ではないが、正本の「一般SPOT廃止」と商品境界が一致していない。

## 3. CASETRA実装との照合

### Platform料金

- 契約申込、企業設定、請求fallback: STARTER 40,000円、STANDARD 60,000円、PLUS 99,000円
- `billingPlans.v1.json`: Case・予約の枠と超過単価は正本どおり
- `billingPlans.v1.json`の`base_fee_yen: 0`: 不一致ではない。Platform月額を企業月額またはfallbackで別行計上し、二重課金を防ぐ現行実装

### KIDUKI契約者料金

料金マスターの主なオンライン契約者料金は正本と一致する。

| 業務 | 実装 | 正本 |
|---|---:|---:|
| 健康相談等 | 14,000円 | 14,000円 |
| ストレス・その他面談 | 20,000円 | 20,000円 |
| 復職・体調相談 | 27,000円 | 27,000円 |
| 人事フィードバック15分 | 10,000円 | 10,000円 |
| 人事フィードバック30分 | 20,000円 | 20,000円 |
| 診療情報提供依頼書等 | 5,000円 | 5,000円 |

一方、料金マスターには旧SPOT SKUが残る。一般SPOTを廃止する正本に合わせ、外部申込や通常予約から選べないことを確認し、必要なら履歴用・同一案件追加対応用へ用途を限定する。
