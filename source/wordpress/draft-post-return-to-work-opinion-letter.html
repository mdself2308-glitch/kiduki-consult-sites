復職時の産業医意見書は、単に「復職可・不可」を伝える書面ではありません。会社が実際に勤務条件を決められるよう、就業上の措置、その開始日、再評価日、変更・解除の条件を明確にすることが重要です。産業医の意見と会社の決定は、分けて記録します。

意見書で確認したい7項目

  1. 評価に用いた情報
  2. 就業可否または就業区分
  3. 勤務時間に関する措置
  4. 業務内容・安全面の制限
  5. 措置の開始日
  6. 次回の再評価日
  7. 変更・解除を検討する条件

産業医意見と会社決定は同じものではありません

産業医等は、本人の医学的状態と実際の職務情報を踏まえ、就業上の措置について医学的意見を示します。配置、労働時間、担当業務などの最終決定と実施は会社が行います。

そのため、記録上も「医師が示した意見」と「会社が採用した措置」を分けます。意見を一部変更して実施する場合は、実施可能性、本人との話合い、代替措置などの検討経過を残します。

会社が使える意見書に必要な具体性

実際の意見は、個別の医学的状態と職務に応じて作成します。定型文へ本人を当てはめるのではなく、会社から正確な職務情報を産業医等へ渡すことが前提です。

意見書を受け取った会社の実務

  1. 内容を確認：実施できない条件や解釈が分かれる表現を産業医等へ確認します。
  2. 本人と話し合う：必要な範囲で意見を説明し、勤務条件と連絡方法を確認します。
  3. 会社が決定：措置、開始日、対象業務、決定者を記録します。
  4. 職場へ実装：勤務表、業務分担、上司への伝達へ反映します。
  5. 再評価を予約：復職後の確認日を予定表と案件記録へ登録します。

会社へ共有する情報は必要最小限にする

職場が必要とするのは、診断名や治療内容の詳細ではなく、安全に働くための勤務条件や配慮です。上司へ共有する内容と、人事・産業保健職だけが取り扱う情報を分けます。

共有の原則：誰に、何の目的で、どこまで伝えるかを確認します。病名を広く知らせる代わりに、「時間外勤務を行わない」「定期通院の時間を確保する」など、職場が実施する事項を共有します。

意見書の発行で案件を終わらせない

意見書を保管しただけでは、措置を実施した証拠にはなりません。会社の決定、本人・上司への伝達、勤務表等への反映、復職後の状況、再評価結果までを一つの経過として残します。

復職後の進め方は、復職後の再評価と就業制限の解除で詳しく解説します。
