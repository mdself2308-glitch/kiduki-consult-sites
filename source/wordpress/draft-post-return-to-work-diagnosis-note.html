主治医から「復職可能」と書かれた診断書が提出されても、会社がそのまま元の勤務へ戻すと決めるとは限りません。診断書は治療を担当する主治医の医学的見解です。会社は、実際の職務と職場の受入体制を確認し、必要に応じて産業医等の意見を聴いたうえで、復職日と就業上の措置を決定します。

診断書を受け取った後の5つの確認

  1. 診断書が示している範囲
  2. 復職先で実際に求められる職務
  3. 安定して勤務を続ける準備性
  4. 会社が実施できる就業上の措置
  5. 復職後の再評価日と解除条件

「復職可能」は元の仕事を制限なくできるという意味ではありません

主治医は、本人の症状、治療経過、日常生活の状態等から医学的見解を示します。一方で、職場の具体的な業務、勤務時間、通勤、出張、運転、夜勤、対人負荷、繁忙期の予定まで把握しているとは限りません。

厚生労働省の職場復帰支援に関する情報でも、主治医による復職可能の判断が、職場で求められる業務遂行能力まで回復しているとの判断とは限らないため、職務情報を踏まえて産業医等が精査することの重要性が示されています。

1. 診断書が示している範囲を読む

最初に、診断名だけでなく、復職可能日、通院継続の要否、勤務時間や残業への言及、避けるべき業務、再診予定などを確認します。「復職可能」「軽減勤務が望ましい」といった抽象的な表現だけでは、会社が勤務条件を決められないことがあります。

不足情報がある場合：本人の同意を得たうえで、主治医に職務内容や会社が検討している勤務条件を伝え、就業上必要な範囲に限って追加情報を確認します。病歴全体の提出を一律に求めるのではなく、目的と閲覧者を限定します。

2. 復職先で求められる職務を具体化する

「事務職」「営業職」のような職種名だけでは判断材料として不十分です。復職初日から何時に出勤し、どの仕事を、どの程度の量で担当するのかまで分解します。

3. 安定して勤務を続ける準備性を確認する

症状が軽くなったかだけでなく、決まった時刻に起床し、通勤し、日中の活動を保ち、翌日に回復できる状態かを確認します。集中力、疲労、服薬による眠気、生活リズム、通勤負荷などは、実際の職務との組合せで評価します。

睡眠と生活リズムの確認方法は、復職判断で見る睡眠・生活リズムで詳しく整理します。

4. 会社が実施できる就業上の措置へ落とす

  • 短時間勤務や段階的な勤務時間延長
  • 残業、深夜勤務、休日勤務、出張の制限
  • 高負荷業務、運転、単独勤務等の一時的な制限
  • 業務量、締切、顧客対応、役割の調整
  • 上司との定期確認と産業医等による再面談

医学的に望ましい配慮でも、会社が実施できなければ運用は続きません。代替案を含めて検討し、最終的な勤務条件は会社が決定します。

5. 復職時に再評価日と解除条件を決める

残業禁止や短時間勤務を設定する場合は、開始日だけでなく、次に見直す日と、何を確認できれば変更・解除するかを決めます。期限のない制限は、本人にも職場にも負担となり、必要以上に長期化することがあります。

再評価の実務は、復職後の再評価と就業制限の解除で解説します。
