# 手順書02 Googleに「このページを見に来て」と頼む（Search Console の URL検査）

作成: 2026-09-02 ／ 所要時間: 5分 ／ 必要なもの: 事務所のGoogleアカウントでログインできるChrome

## 何のため

今日書き換えた「スポット産業医」のページを、Googleに早く読み直してもらうためです。頼まなくても数日〜数週間で読み直されますが、頼むと早まることがあります。順位が上がる約束ではありません。

## やること

1. Chrome で次のページを開きます（そのままコピーして貼ってください）。
   https://search.google.com/search-console/
2. ログイン画面が出たら、事務所のGoogleアカウント（kdkconsult.sngyijm@gmail.com）でログインします。パスワードやパスキーはご自身で入力してください。
3. 画面の**左上**に、サイトの名前と **▼** があります。そこを押して、**「https://kdkconslt-sngyouijm.com/」** を選びます（「consult.」で始まる方ではありません）。
4. 画面の**一番上の細長い検索窓**（「https://kdkconslt-sngyouijm.com/ 内のすべての URL を検査」と薄く書いてある）を押し、次をコピーして貼り付け、**Enter** を押します。
   https://kdkconslt-sngyouijm.com/service/return-to-work-support/
5. 「Google インデックスからデータを取得しています」と出るので、そのまま **1分ほど待ちます。**
6. 結果が出たら、**右側にある「インデックス登録をリクエスト」** という文字（ボタン）を押します。
7. 「リクエストを処理しています」と出て、1〜2分で **「インデックス登録をリクエスト済み」** と表示されれば成功です。「OK」を押して閉じます。
8. もう一度、一番上の検索窓に次を貼り付けて Enter を押します。
   https://kdkconslt-sngyouijm.com/service/spot/
9. 「ページにリダイレクトがあります」または「URL が Google に登録されていません」と出れば正常です（古いページが新しいページへ転送されている、という意味）。**ここでは何も押しません。**
10. チャットに **「URL検査した」** と返してください。

## うまくいかないとき

- 手順3で「https://kdkconslt-sngyouijm.com/」が一覧に無い場合は、ログインしたアカウントが違います。右上の丸いアイコンから事務所のアカウントに切り替えてください。
- 手順6で「インデックス登録をリクエスト」が押せない・「割り当てを超えました」と出る場合は、今日はここまでで大丈夫です。明日もう一度手順4〜7をやります。
- 何が出たか分からないときは、画面の文字をコピーしてチャットに貼ってください。
