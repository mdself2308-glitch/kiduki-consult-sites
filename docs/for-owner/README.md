## Claudeに任せる設定（任意・やると先生の作業が減ります）

- **ブラウザ操作を任せる**: Chrome に「Claude in Chrome」拡張機能を入れて、このアプリと同じアカウントでサインインすると、手順書02・03のような画面操作は私が代わりにできます（先生はログインしたChromeを開いておくだけ）。入れる場所: https://chromewebstore.google.com/detail/fcoeoabgfenejglbffodgkkbkcdhcgfn
- **git（公開の送信）を任せる**: 今回は私の `git` 操作が安全装置で止まりました。チャットで「gitを許可」と言っていただければ、このプロジェクトだけ許可する設定を私が追加し、次回から手順書01の「Run」も不要になります。

## 書き方の約束（手順書を追加するとき）

1. どのアプリ・どのページを開くか（URLをそのまま）
2. 画面のどこを押すか（位置と、ボタンの文字そのまま）
3. 何を入力・貼り付けるか
4. 成功したら何が見えるか
5. 失敗したら何をするか（多くは「出た文字をコピーして貼ってください」）
