# 手順書03 Search Console に「ドメインプロパティ」を追加する（2つのサイトを1つの画面で見る）

作成: 2026-09-02 ／ 所要時間: 15分 ／ 必要なもの: 事務所のGoogleアカウント、Xserver（エックスサーバー）のサーバーパネルにログインできること

## 何のため

いま Search Console（＝Googleが「あなたのサイトが検索でどう見られたか」を教えてくれる画面）は、トップページ（consult.〜）と記事・サービス（kdkconslt-〜）が**別々のサイト**として登録されています。「ドメインプロパティ」を追加すると、**2つを1つの画面でまとめて見られる**ようになります。

やり方は「Googleが出す合言葉を、ドメインの住所帳（DNS）に書き込む」です。DNSは Xserver が管理しています（2026-09-02 に確認）。

## パートA Googleから合言葉をもらう

1. Chrome で https://search.google.com/search-console/ を開き、事務所のGoogleアカウントでログインします。
2. **左上**のサイト名の **▼** を押し、一覧の**一番下**の **「＋ プロパティを追加」** を押します。
3. 左側の **「ドメイン」** の枠に、次を入力します。
   kdkconslt-sngyouijm.com
4. **「続行」** を押します。
5. 「DNS レコードでのドメイン所有権の確認」という画面が出ます。真ん中に `google-site-verification=` から始まる長い文字があります。その右の **「コピー」** を押します。
6. **この画面は閉じずに、そのまま置いておきます。**

## パートB Xserverの住所帳（DNS）に書き込む

1. Chrome で**新しいタブ**を開き、次のページを開きます。
   https://secure.xserver.ne.jp/xapanel/login/xserver/server/
2. Xserverの**サーバーID とパスワード**でログインします（ご自身で入力してください）。
3. 「サーバーパネル」が開きます。**「ドメイン」** という見出しの中の **「DNSレコード設定」** を押します。
4. ドメインの一覧から **kdkconslt-sngyouijm.com** の右にある **「選択する」** を押します。
5. 上のタブで **「DNSレコード追加」** を押します。
6. 次のように入力します。
   - **ホスト名**: 何も入力しない（空のまま）
   - **種別**: 「TXT」を選ぶ
   - **内容**: パートAでコピーした `google-site-verification=…` を貼り付ける
   - **優先度**: そのまま（触らない）
7. **「確認画面へ進む」** を押し、内容を見て **「追加する」** を押します。「DNSレコードの追加を完了しました」と出れば成功です。
8. **注意**: 一覧にある `v=spf1 …` で始まる別のTXTレコードは**メール用**です。絶対に消さないでください。

## パートC Googleに「書き込んだよ」と伝える

1. パートAの Search Console のタブに戻ります。
2. **「確認」** を押します。
3. **「所有権を証明しました」** と出れば完了です。**「プロパティに移動」** を押すと、新しい画面（kdkconslt-sngyouijm.com）が開きます。
4. 「確認できませんでした」と出た場合は、住所帳の反映に時間がかかっているだけです。**30分〜1時間後にもう一度「確認」を押してください。** それでもダメなら、出た文字をコピーしてチャットに貼ってください。
5. 完了したら、チャットに **「ドメインプロパティできた」** と返してください。今ある2つの登録（consult.〜 と kdkconslt-〜）は消さずに残します。

## うまくいかないとき

- Xserverのログイン情報が分からない: Xserverからの契約メール（件名に「サーバーアカウント設定完了」）にサーバーIDがあります。パスワードはXserverのサイトで再設定できます。
- 「DNSレコード設定」が見つからない: サーバーパネルの画面を下にスクロールすると「ドメイン」の欄があります。
