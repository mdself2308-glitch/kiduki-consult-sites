# 手順書06 顧客企業に Google の口コミを頼む（業務完了の報告直後に、1社ずつ）

作成: 2026-09-02 ／ 所要時間: 10分（リンク取得3分＋メール送信）

## 何のため

「産業医 東京」「産業医 港区」で検索すると、上の方に**地図つきの枠（3社まで）**が出ます。ここに入るかどうかは、**口コミの数・新しさ・内容**で大きく決まります。いまKIDUKIの口コミは0件です。ただし、この土俵の競合も口コミ0〜6件で商談量は小さいので、**急いで集める必要はありません**。業務の完了を報告した会社に、その直後に1社ずつお願いし、年3〜4件を上限にします（Googleは短期間に集中した口コミを不自然と見ることがあります）。

頼むのは**会社の担当者として**の口コミです。従業員（面談を受けた本人）には頼みません。健康情報が書かれる恐れがあるためです。

## パートA 口コミ用のリンクを取る（3分）

1. Chrome で https://business.google.com/ を開きます（事務所のGoogleアカウント）。
2. 事務所のプロフィールを開き、**「クチコミを読む」** → **「クチコミを増やす」**（共有の印）を押します。見つからないときは、画面上の「…」（その他）の中にあります。
3. `https://g.page/r/……/review` のような**短いリンク**が出ます。右の **「コピー」** を押します。
4. このリンクを、下のメール文の【口コミリンク】の場所に貼ります。

## パートB メールを送る（業務完了を報告した会社の担当者に、1社ずつ）

頼む相手は「直近12か月に業務が完了した会社の人事・総務・安全衛生の担当者」です。感謝の言葉があった人だけを選ばないでください（良い評価だけを集める依頼と見なされます）。件名と本文はそのまま使えます。【 】の中だけ書き換えてください。

件名: 産業医業務についての率直なご感想をいただけませんか

```
【会社名】 【ご担当者名】様

いつも産業医業務でお世話になっております。KIDUKIコンサルティング産業医事務所の宮部です。

事務所のGoogle上の紹介ページに、実際にご契約いただいている企業のご担当者としての感想を掲載したく、お願いのご連絡です。

もし差し支えなければ、次のリンクから、当事務所の産業医業務について率直なご感想をお書きいただけますでしょうか。所要時間は2〜3分です。

【口コミリンク】

・会社名や従業員の方の個人名、健康に関する内容は、書かないようお願いいたします。
・ご多忙のところ恐れ入りますが、任意ですので、難しい場合はお気遣いなくお知らせください。

今後ともよろしくお願い申し上げます。

KIDUKIコンサルティング産業医事務所
代表 宮部 大輔
```

## 送ったあと

- 口コミが届いたら、Googleビジネスプロフィールで**返信**します（返信文は私が作ります。「ありがとうございます」だけで終わらせず、業務の姿勢が伝わる短い文にします）。
- チャットに **「口コミ依頼した」** と一言ください。届いた件数は、Googleマップの事務所ページで私が確認します。
- 同じ会社の担当者に、口コミ依頼・紹介資料・Casetraの相談を同じ四半期に重ねてお願いしません。

## 注意

- 口コミの見返りに割引や謝礼を出すことは、Googleのルールで禁止です。
- 内容を指定したり、良い評価だけを頼んだりしません。「率直な感想」でお願いします。
