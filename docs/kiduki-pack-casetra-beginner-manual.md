# KIDUKI復職支援Pack・Casetra 初心者向け運用マニュアル

最終更新: 2026-08-18

## まず覚えること

- 企業が問い合わせ、打合せ、契約をする相手は **KIDUKIコンサルティング産業医事務所** です。
- 150,000円（税別）は、社員1名・1休職エピソードを扱う **KIDUKI復職支援Pack** の料金です。
- Casetraは、契約後に資料、期限、意見書、会社決裁、再評価、証跡を扱うための画面です。
- CasetraのPack専用画面の利用は、15万円のPack料金に含まれます。
- 標準面談は **復職時、復職後1か月、復職後3か月** の3回です。Packは開始から最長6か月で、3か月面談後の再評価とDecision Pack納品で完了します。
- Pack終了後にCasetraを複数案件で継続利用する場合だけ、別途月額契約を案内します。

## 全体の流れ

1. 企業がKIDUKI専用フォームから相談を送る
2. KIDUKIとの15分事前打合せを予約する
3. KIDUKIが打合せを行い、Packの対象と役割分担を確認する
4. 企業とKIDUKIが復職支援Packを契約する
5. KIDUKI OPSが署名済み契約PDFを確認する
6. KIDUKI OPSが企業、担当者、対象社員、復職Caseを一括開始する
7. 企業担当者がKIDUKI名義の案内メールから専用画面を登録する
8. 企業は、今回の1案件について確認、入力、会社決裁を行う
9. KIDUKIは、調整、面談、主治医照会、産業医意見、再評価を進める
10. 終了後は証跡を読取専用で残し、必要な企業だけCasetra月額契約を案内する

## 企業担当者の操作

### 1. KIDUKIへ相談する

1. `https://consult.kdkconslt-sngyouijm.com/return-to-work-pack/` を開きます。
2. 会社名、担当者名、連絡先、現在の段階、希望時期を入力します。
3. 「KIDUKIへ相談を送信」を押します。
4. 画面に表示された受付IDを控えます。
5. 続けて「KIDUKIとの事前打合せを予約」を押し、日時を選びます。

この時点では、社員氏名、病名、診断書、症状などの健康情報を入力・送信しません。

### 2. KIDUKIと事前打合せをする

KIDUKIが次を確認します。

- いま止まっている工程
- 受領済みの資料と不足資料
- 希望する開始時期
- KIDUKIが行う処理と会社が行う処理
- PackはKIDUKIとの契約であること
- 契約後にCasetraのPack専用画面を使うこと

### 3. 契約後、専用画面を登録する

1. 件名が「【KIDUKI復職支援Pack】専用画面の登録手続き」のメールを開きます。
2. 「KIDUKI復職支援Pack専用画面を登録する」を押します。
3. 登録画面上部の「ご契約先はKIDUKIです」を確認します。
4. Microsoftアカウント、組織Microsoftアカウント、メール確認コードのいずれかで登録します。
5. 登録後、「Case管理」へ移動します。

登録画面と案件画面にはCasetraのロゴが表示されますが、これはKIDUKI復職支援Packの手続き画面です。契約、請求、支援に関する窓口はKIDUKIです。

### 4. Case管理で行うこと

企業担当者に表示されるのは、Packで割り当てられた復職Case 1件だけです。

主に行うことは次のとおりです。

- 会社側の事前情報を確認する
- 主治医照会の要否と目的を確認する
- 産業医意見書を受領する
- 会社の最終決定を入力する
- 復職後の勤務実績、継続・変更・解除を確認する

KIDUKIは次を進めます。

- 不足資料の整理
- 本人、会社、産業医の日程調整
- 本人同意の確認
- 必要時の主治医照会案、送付、回答受領
- 復職面談と勤務準備性・安全性の評価
- 勤務条件、制限、再評価日、解除条件を含む産業医意見
- 復職後1か月・3か月の再評価
- 完了者、完了日時、入力差分、資料を含む証跡整理

復職可否、配置、勤務条件を最終決定し、職場で実施するのは会社です。KIDUKIは会社に代わって人事決裁を行いません。

## KIDUKI OPSの操作

OPS画面: `https://core.casetra.jp/ops/pack`

### 1. 問い合わせを確認する

1. OPS画面へログインします。
2. 「Pack」を開きます。
3. 「KIDUKI復職支援Packの問い合わせ」から企業を選びます。
4. 企業名、担当者、現在の段階、希望時期、予約連携を確認します。

問い合わせは受付IDで管理します。通常のCasetra契約申込フォームへ転記しません。

### 2. 事前打合せ完了を記録する

1. 打合せを実施します。
2. 対象範囲、開始時期、役割分担、契約主体を確認します。
3. 「事前打合せ完了を記録」を押します。

### 3. KIDUKI Pack契約を記録する

1. 企業とKIDUKIの契約が締結済みであることを確認します。
2. 署名済み契約PDFをBoxへ保存します。
3. 契約締結日時を入力します。
4. 署名済み契約PDFのBox URLを入力します。
5. 「KIDUKI Pack契約を確認」を押します。

金額は150,000円（税別）です。Casetra SaaS契約、月額プラン、Casetra請求を作成しません。いったん記録した署名済み契約証跡は差し替えできません。

### 4. 企業アカウントと復職Caseを一括開始する

1. 社内管理番号を入力します。氏名や病名ではなく、企業内で識別できる番号を推奨します。
2. 必要な場合だけ、契約後の情報として対象社員名と部署を入力します。
3. 案件起点日、KIDUKI担当、企業の操作期限を確認します。
4. 「企業登録・復職Case・Pack権限を一括開始」を押します。
5. 登録案内メールが「送信済み」になったことを確認します。

一括開始により、次が同じ受付IDで作られます。

- 企業
- 企業担当者
- 対象社員
- 復職支援の標準Case
- `PACK_INCLUDED` の請求区分
- 当該Case 1件だけを操作できるPack権限
- 企業担当者の登録URL

## 状態の見方

| 状態 | 意味 | 次にすること |
|---|---|---|
| `NEW` | KIDUKIが相談を受け付けた | 事前打合せを行う |
| `CONSULTATION_DONE` | 事前打合せ完了 | KIDUKI Pack契約を締結・確認する |
| `PACK_CONTRACT_SIGNED` | KIDUKI契約の証跡確認済み | 企業・担当者・復職Caseを一括開始する |
| `PACK_ACTIVE` | Pack稼働中 | CaseのToDoと証跡を進める |
| `READ_ONLY` | 操作終了、証跡閲覧のみ | 継続方法を選ぶ |
| `DISABLED` | Packアクセス停止 | KIDUKI OPSへ確認する |

## 絶対にしないこと

- KIDUKIへの相談をCasetra月額契約の問い合わせとして扱わない
- Pack契約前に社員の健康情報を公開フォームや通常メールで受け取らない
- 事前打合せ前に契約完了へ進めない
- 署名済みKIDUKI契約PDFを確認せずにPackを開始しない
- Pack企業へSTARTER、STANDARD、PLUSの月額契約を自動設定しない
- Pack案件をCasetra月額の利用件数や超過件数へ算入しない
- 企業担当者へ他社・他Caseを表示しない
- 契約証跡を後から上書きしない

## 困ったとき

### 受付後のメールが届かない

- 迷惑メールフォルダを確認します。
- 受付IDが画面に表示されていれば、相談自体は受け付けられています。
- KIDUKI OPSで問い合わせ一覧とメール送信状態を確認します。

### 予約が問い合わせに連携されない

- 企業が受付完了画面またはKIDUKI受付メール内の予約ボタンから予約したか確認します。
- OPSの問い合わせに予約IDが表示されるか確認します。
- メールアドレスと受付IDを照合します。

### 登録後に案件が表示されない

- 企業担当者が案内先と同じメールアドレスで登録したか確認します。
- OPSで `PACK_ACTIVE`、Case ID、登録URL、操作期限を確認します。
- 一度ログアウトし、再ログインします。

### 他の案件や請求画面が見える

Pack権限の異常です。操作を続けず、直ちにKIDUKI OPSへ連絡します。Pack企業は割り当てられた1件だけが表示され、請求画面は表示されないのが正常です。

### 操作できない

操作期限を過ぎると `READ_ONLY` になり、入力済み内容と証跡の閲覧だけができます。継続操作が必要な場合はKIDUKI OPSが期限と契約状況を確認します。

## Pack終了後の選択肢

企業には次の三つを案内します。

1. Casetraを別途月額契約し、同じ処理を複数案件で自社運用する
2. 6か月時点、再燃時、制限解除時など、必要な回だけKIDUKIへ単発フォローを依頼する
3. 証跡を引き継ぎ、自社または既存産業医の運用へ戻す

Casetra月額契約は自動更新・自動移行にしません。企業が内容と料金を確認し、別途申込み・契約した場合だけ開始します。

KIDUKI単発フォローも自動延長ではありません。対象となる再評価、料金、再開する閲覧・操作期限を企業と合意した後、OPSが既存Caseを必要な期間だけ再開します。合意がない限り、Packは読取専用のままです。
