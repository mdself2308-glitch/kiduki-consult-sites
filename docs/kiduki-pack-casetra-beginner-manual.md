# KIDUKI復職支援Pack／単発支援・Casetra 初心者向け運用マニュアル

最終更新: 2026-08-18

## まず覚えること

- 企業が問い合わせ、打合せ、契約をする相手は **KIDUKIコンサルティング産業医事務所** です。
- 150,000円（税別）は、社員1名・1休職エピソードを扱う **KIDUKI復職支援Pack** の料金です。
- Casetraは、契約後に資料、期限、意見書、会社決裁、再評価、証跡を扱うための画面です。
- CasetraのPack専用画面の利用は、15万円のPack料金に含まれます。
- 標準面談は **復職時、復職後1か月、復職後3か月** の3回です。各面談後に産業医意見書を1通ずつ発行し、企業の受領確認と会社決裁まで記録します。Packは開始から最長6か月で、3か月面談後の再評価とDecision Pack納品で完了します。
- Pack終了後にCasetraを複数案件で継続利用する場合だけ、別途月額契約を案内します。
- 必要な1回だけを依頼する企業には、オンライン60,000円または訪問75,000円＋交通費（税別）のKIDUKI単発支援を案内します。面談1回、意見書1通と前後処理を含み、案件限定画面は30日間です。

## 全体の流れ

1. 企業がKIDUKI専用フォームから相談を送る
2. KIDUKIとの15分事前打合せを予約する
3. KIDUKIが打合せを行い、Packの対象と役割分担を確認する
4. 企業とKIDUKIが復職支援Packを契約する
5. KIDUKI OPSが署名済み契約PDFを確認する
6. KIDUKI OPSが企業、担当者、対象社員、復職Caseを一括開始する
7. 企業担当者がKIDUKI名義の案内メールから専用画面を登録する
8. 企業は、今回の1案件について確認、入力、会社決裁を行う
9. KIDUKIは、調整、面談、主治医照会、産業医意見、再評価を進める
10. 終了後は証跡を読取専用で残し、必要な企業だけ同じアカウントからCasetra月額利用を申し込む

## 企業担当者の操作

### 1. KIDUKIへ相談する

1. `https://consult.kdkconslt-sngyouijm.com/return-to-work-pack/` を開きます。
2. 会社名、担当者名、連絡先、現在の段階、希望時期を入力します。
3. 「KIDUKIへ相談を送信」を押します。
4. 画面に表示された受付IDを控えます。
5. 続けて「KIDUKIとの事前打合せを予約」を押し、日時を選びます。

この時点では、社員氏名、病名、診断書、症状などの健康情報を入力・送信しません。

### 2. KIDUKIと事前打合せをする

KIDUKIが次を確認します。

- いま止まっている工程
- 受領済みの資料と不足資料
- 希望する開始時期
- KIDUKIが行う処理と会社が行う処理
- PackはKIDUKIとの契約であること
- 契約後にCasetraのPack専用画面を使うこと

### 3. 契約後、専用画面を登録する

1. 件名が「【KIDUKI復職支援Pack】専用画面の登録手続き」のメールを開きます。
2. 「KIDUKI復職支援Pack専用画面を登録する」を押します。
3. 登録画面上部の「ご契約先はKIDUKIです」を確認します。
4. Microsoftアカウント、組織Microsoftアカウント、メール確認コードのいずれかで登録します。
5. 登録後、「Case管理」へ移動します。

登録画面と案件画面にはCasetraのロゴが表示されますが、これはKIDUKI復職支援Packの手続き画面です。契約、請求、支援に関する窓口はKIDUKIです。

### 4. Case管理で行うこと

企業担当者に表示されるのは、Packで割り当てられた復職Case 1件だけです。

主に行うことは次のとおりです。

- 会社側の事前情報を確認する
- 主治医照会の要否と目的を確認する
- 産業医意見書を受領する
- 会社の最終決定を入力する
- 復職後の勤務実績、継続・変更・解除を確認する

KIDUKIは次を進めます。

- 不足資料の整理
- 本人、会社、産業医の日程調整
- 本人同意の確認
- 必要時の主治医照会案、送付、回答受領
- 復職面談と勤務準備性・安全性の評価
- 各面談後に、勤務条件、制限、再評価日、解除条件を含む産業医意見書を発行
- 復職後1か月・3か月の再評価
- 完了者、完了日時、入力差分、資料を含む証跡整理

復職可否、配置、勤務条件を最終決定し、職場で実施するのは会社です。KIDUKIは会社に代わって人事決裁を行いません。

## KIDUKI OPSの操作

OPS画面: `https://core.casetra.jp/ops/pack`

### 1. 問い合わせを確認する

1. OPS画面へログインします。
2. 「KIDUKI案件」を開きます。
3. 「KIDUKI復職支援の問い合わせ」から企業を選びます。
4. 企業名、担当者、現在の段階、希望時期、予約連携を確認します。

問い合わせは受付IDで管理します。通常のCasetra契約申込フォームへ転記しません。

### 2. 事前打合せ完了を記録する

1. 打合せを実施します。
2. 対象範囲、開始時期、役割分担、契約主体を確認します。
3. 「事前打合せ完了を記録」を押します。

### 3. KIDUKI Pack契約を記録する

1. 企業とKIDUKIの契約が締結済みであることを確認します。
2. 署名済み契約PDFをBoxへ保存します。
3. 契約締結日時を入力します。
4. 署名済み契約PDFのBox URLを入力します。
5. 「KIDUKI Pack契約を確認」を押します。

金額は150,000円（税別）です。Casetra SaaS契約、月額プラン、Casetra請求を作成しません。いったん記録した署名済み契約証跡は差し替えできません。

### 4. 企業アカウントと復職Caseを一括開始する

1. 社内管理番号を入力します。氏名や病名ではなく、企業内で識別できる番号を推奨します。
2. 必要な場合だけ、契約後の情報として対象社員名と部署を入力します。
3. 案件起点日、KIDUKI担当、企業の操作期限を確認します。
4. 「企業登録・復職Case・Pack権限を一括開始」を押します。
5. 登録案内メールが「送信済み」になったことを確認します。

一括開始により、次が同じ受付IDで作られます。

- 企業
- 企業担当者
- 対象社員
- 復職支援の標準Case
- `PACK_INCLUDED` の請求区分
- 当該Case 1件だけを操作できるPack権限
- 企業担当者の登録URL

### 5. Casetra月額利用へ切り替える

自動移行はしません。次の順番をすべて満たした場合だけ限定解除します。

1. 企業担当者がCase管理の「同じアカウントをCasetra月額利用へ」で希望プランを選び、申込依頼を送ります。この操作だけでは契約・課金・限定解除は行われません。
2. KIDUKI／Casetra側で月額条件を説明し、企業とCasetra月額契約を別途締結します。
3. OPSは署名済みCasetra月額契約PDFをBoxへ保存します。
4. `/ops/pack` の「月額契約確認・案件限定解除」で企業、確定プラン、契約締結日時、月初の課金開始日、Box URL、予約リンク送付有無を確認します。
5. 確認チェックを入れ、「契約を確定して案件限定を解除」を押します。
6. 同じ企業IDと担当者アカウントが `FULL` になり、会社情報、KIDUKI Case、Todo、意見書、証跡を保持したまま全社機能が開きます。開いている企業画面も自動確認し、再登録なしで切り替わります。

既存Pack Caseは `PACK_INCLUDED`、単発Caseは `KIDUKI_SPOT_INCLUDED` のままです。Casetra月額や面談従量へ付け替えません。月額料金は登録した課金開始月から、新しく開始する通常Caseは `CLIENT_BILLABLE` として扱います。

## 状態の見方

| 状態 | 意味 | 次にすること |
|---|---|---|
| `NEW` | KIDUKIが相談を受け付けた | 事前打合せを行う |
| `CONSULTATION_DONE` | 事前打合せ完了 | KIDUKI Pack契約を締結・確認する |
| `PACK_CONTRACT_SIGNED` | KIDUKI契約の証跡確認済み | 企業・担当者・復職Caseを一括開始する |
| `PACK_ACTIVE` | Pack稼働中 | CaseのToDoと証跡を進める |
| `READ_ONLY` | 操作終了、証跡閲覧のみ | 継続方法を選ぶ |
| `DISABLED` | Packアクセス停止 | KIDUKI OPSへ確認する |
| `REQUESTED` | Casetra月額利用の申込依頼済み | 別契約・Box証跡・開始月を確認する |
| `ACTIVATED` | 別契約確認後、同じアカウントをFULLへ限定解除済み | 新規Caseから月額契約条件で運用する |

## 絶対にしないこと

- KIDUKIへの相談をCasetra月額契約の問い合わせとして扱わない
- Pack契約前に社員の健康情報を公開フォームや通常メールで受け取らない
- 事前打合せ前に契約完了へ進めない
- 署名済みKIDUKI契約PDFを確認せずにPackを開始しない
- Pack企業へSTARTER、STANDARD、PLUSの月額契約を自動設定しない
- Pack案件をCasetra月額の利用件数や超過件数へ算入しない
- 署名済みCasetra月額契約PDFと課金開始月を確認せずにFULLへ変更しない
- Cosmos上の担当者権限や契約フラグだけを手作業で変更しない
- 企業担当者へ他社・他Caseを表示しない
- 契約証跡を後から上書きしない

## 困ったとき

### 受付後のメールが届かない

- 迷惑メールフォルダを確認します。
- 受付IDが画面に表示されていれば、相談自体は受け付けられています。
- KIDUKI OPSで問い合わせ一覧とメール送信状態を確認します。

### 予約が問い合わせに連携されない

- 企業が受付完了画面またはKIDUKI受付メール内の予約ボタンから予約したか確認します。
- OPSの問い合わせに予約IDが表示されるか確認します。
- メールアドレスと受付IDを照合します。

### 登録後に案件が表示されない

- 企業担当者が案内先と同じメールアドレスで登録したか確認します。
- OPSで `PACK_ACTIVE`、Case ID、登録URL、操作期限を確認します。
- 一度ログアウトし、再ログインします。

### 他の案件や請求画面が見える

Pack権限の異常です。操作を続けず、直ちにKIDUKI OPSへ連絡します。Pack企業は割り当てられた1件だけが表示され、請求画面は表示されないのが正常です。

### 操作できない

操作期限を過ぎると `READ_ONLY` になり、入力済み内容と証跡の閲覧だけができます。継続操作が必要な場合はKIDUKI OPSが期限と契約状況を確認します。

## Pack終了後の選択肢

企業には次の三つを案内します。

1. Casetraを別途月額契約し、同じ処理を複数案件で自社運用する
2. 6か月時点、再燃時、制限解除時など、必要な回だけKIDUKIへ単発フォローを依頼する
3. 証跡を引き継ぎ、自社または既存産業医の運用へ戻す

Casetra月額契約は自動更新・自動移行にしません。企業が同じアカウントから申込依頼を送り、内容と料金を確認して別途契約し、OPSが署名済み契約PDFと課金開始月を確認した場合だけ開始します。企業・担当者・既存証跡は移し替えず、案件限定だけを解除します。

KIDUKI単発フォローも自動延長ではありません。対象となる再評価、料金、再開する閲覧・操作期限を企業と合意した後、OPSが既存Caseを必要な期間だけ再開します。合意がない限り、Packは読取専用のままです。

## KIDUKI単発支援の処理

### 企業側

1. `https://consult.kdkconslt-sngyouijm.com/return-to-work-spot/` を開きます。
2. オンラインまたは訪問を選び、会社情報、現在の段階、希望時期を送信します。健康情報は送信しません。
3. KIDUKIとの15分事前打合せで、対象、期限、追加調整・文書の有無を確認します。
4. KIDUKI単発契約を締結します。オンライン60,000円、訪問75,000円＋交通費、緊急・複雑案件は80,000円からの個別見積です。
5. KIDUKI名義の登録メールから案件限定画面を登録します。
6. 表示された1 Caseで、資料確認、意見書受領、会社決裁、次回期限を処理します。

### KIDUKI OPS側

1. `https://core.casetra.jp/ops/pack` の「KIDUKI案件管理」で単発問い合わせを選びます。
2. 事前打合せ完了を記録します。
3. 署名済みKIDUKI契約PDFをBoxへ保存し、契約日時、URL、金額を記録します。緊急・複雑案件だけ、80,000円以上の合意額を入力します。
4. 「企業登録・復職Case・限定権限を一括開始」を押します。
5. `SPOT` 権限、`KIDUKI_SPOT_INCLUDED` 請求区分、対象1 Case、30日の期限、登録URLが作られたことを確認します。
6. 登録案内メールが送信済みであることを確認します。

単発料金には、事前情報整理、日程・不足情報の調整、産業医面談1回（標準40分）、産業医意見書1通、会社の受領・決裁、証跡整理を含みます。追加面談、追加文書、主治医照会等は、必要性と費用を開始前に合意します。

単発Caseでは、Casetra月額契約、Case超過、予約超過、面談従量請求を作りません。面談実績は証跡として残しますが、請求明細の状態は `included` となり、Casetra請求書へ入りません。30日後は `READ_ONLY` となり、別途Casetra月額契約を締結しない限り全社機能は開放しません。
